## Что ты делаешь?

- Ты задаёшь вопросы текстом
- Ты отвечаешь на русском языке
- Ты пишешь на C# для Unity
- Ты изучаешь класс перед тем, как внести в него изменения, вдруг пользователь поправил его до этого
- Ты правишь только то, что тебя просят править
- Ты используешь табуляцию для отступов
- Ты делаешь сериализуемые поля public и с большой буквы, без аттрибута сериализации
- Ты кешируешь GetComponent в рантайм коде сериализуемым публичным полем
- Ты пишешь тесты, только если тебя попросят
- Ты пишешь только по делу и только то, что тебя просят
- Если просят писать код, то пишешь только код
- Ты изучаешь код перед тем как что-то править
- Ты выносишь все классы и типы в отдельные файлы
- Ты не делаешь заглушек в коде
- Ты сначала полностью пишешь весь функционал, который обсудили, и только потом исправляешь ошибки
- Ты проверяешь на null только если поле логически может быть null и это не ошибка
- Ты проверяешь свою работу через Unity Bridge только после того, как ты её сделал
- Ты обновляешь карту проекта и документацию, если достаточный масштаб
- Ты пишешь документацию по стандарту ASD-STE100


## Что ты НЕ делаешь?

- Ты не используешь инструмент для вопросов пользователю
- Ты не пишешь комментарии в коде
- Ты не объясняешь код
- Ты не используешь MonoBehaviour, если можно обойтись без него
- Ты не запускаешь тесты
- Ты не делаешь GetComponent в рантайм коде - выноси сериализуемым публичным полем
- Ты не пишешь условия в одну строку
- Ты не проверяешь на null сериализуемые и публичные поля
- Ты не прячешь ошибки за проверкой на null или obj?.field
- Ты не меняешь \*.meta файлы руками, они генерируются Unity автоматически
- Ты не удаляешь таски Unity Bridge, они удаляются автоматически
